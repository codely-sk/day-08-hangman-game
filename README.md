# Day 08 – Hangman Game 🎯

## About the Project
Hangman is a Python word-guessing game in which the player tries to guess a secret word one letter at a time. The player gets a limited number of attempts and receives a hint showing the first letter of the word.

## Features
- Random word selection
- First-letter hint
- Limited attempts
- Checks invalid and repeated guesses
- Displays the final result

## Concepts Used
- Variables and strings
- Lists and sets
- `while` and `for` loops
- `if-else` conditions
- User input and validation
- `random.choice()`

## What I Learned
- How to select a random word
- How to store guessed letters using a set
- How to display hidden letters
- How to use loops and conditions to manage a game
- How to validate user input

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run `day_08_hangman.py`.
